### PRINTED VARIANTS OF THE FIRST EDITION OF THE ARTICLE “IT IS TIME TO UNDERSTAND!” AGAINST THE MAIN TEXT

Page 443, line 5. *Instead of:* and, what is most terrible of all, ruins the soul — *in the first edition:* ruins the soul.

Page 443, line 11. *Instead of:* encourage them — *in the first edition:* encourage him.

Page 443, line 28. *Instead of:* when many doctors — *in the first edition:* when all doctors.

Page 444, line 2. *Instead of:* harmful — *in the first edition:* always harmful.

Page 444, line 5. *Instead of:* will do much less work — *in the first edition:* will do much less work; therefore she also has less strength.

Page 444, line 9. *Instead of:* only for a short time, but in the long run — *in the first edition:* only in the short run, and in the long run.

Page 444, line 15. *Instead of:* discuss the matter — *in the first edition:* discuss the matter; and therefore, if one is going to drink at all, it is better at an ordinary time.

Page 444, line 21. *Instead of:* for a short time — *in the first edition:* in the short run.

Page 444, line 31. *Instead of:* so many people — *in the first edition:* everyone.

Page 444, line 32. *Instead of:* “Everyone drinks.... — *in the first edition:* There is one answer to this: “Everyone drinks....

Page 444, line 33. *Instead of:* to this many — *in the first edition:* to this people.

Page 444, line 34:

<!-- vol. 26, p. 458 -->

*Instead of:* these people actually imagine that everyone around them drinks — *in the first edition:* they actually think that everyone drinks.

Page 445, line 3. *Instead of:* If they came to blows — *in the first edition:* But what if they came to blows.
